# Este panel en un sitio del kit

Copia del CMS de IIDEA/Alpha. Git es la base. No es WordPress ni Storyblok.

- Identidad: `client.config.json` (sale del brief).
- El sitio es la raíz del repo: `github.siteDir` vacío, `SITE_DIR` vacío.
- Entradas → `src/content/articulos/`.
- Puerto **4322** (el sitio usa 4321).
- Páginas / Carreras / Apariencia / Ajustes van ocultas: el kit no pinta esos
  archivos. Quítalas de `HIDDEN_VIEWS` cuando el sitio las sepa leer.

Arranque y reglas: `~/.cursor/astro-kit/skills/astro-kit/reference/cms.md`.
